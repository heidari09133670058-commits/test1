# ریاضی‌باز

اپلیکیشن ساده آموزش شمارش، جمع، تفریق و شکل‌ها برای کودکان.

## ساخت APK در GitHub
1. تمام محتویات این پوشه را در ریشه مخزن GitHub آپلود کنید.
2. به زبانه Actions بروید.
3. گردش‌کار Build RiaziBaz APK را اجرا کنید (یا منتظر اجرای خودکار پس از Push بمانید).
4. در اجرای موفق، از بخش Artifacts فایل `RiaziBaz-debug-apk` را دریافت کنید.
5. فایل `app-debug.apk` داخل ZIP خروجی است.
